# 从「听说过 VLA」到「跑得通闭环」：Xbotics 具身智能 21 讲逐讲详解

![封面：具身智能 21 讲系统地图](xbotics-21-banner.png)

> 建议作为微信公众号首图。可用「六大部分 + 五个阶段项目」示意图。

---

大模型会「讲」怎么抓杯子，并不等于机器人能稳定抓住杯子。  
具身智能难的地方，往往不在某一个算法名词，而在**整条系统链路**：感知、控制、数据、训练、部署、失败回流——缺一环，热闹就停在 PPT 上。

[Xbotics 具身智能社区](https://github.com/Xbotics-Embodied-AI-club/Xbotics-Embodied-Guide) 出品的《Xbotics 具身智能教程（21 讲）》，正是为这条链路准备的**系统实践课**：不是论文综述，也不是纯科普，而是围绕真实机器人任务、可跑通 Demo、可复盘失败的工程路径。

> **一句话**：Guide 帮你看全局，21 讲带你动手跑完整闭环。

仓库：[Xbotics-Embodied-AI-Handbook](https://github.com/Xbotics-Embodied-AI-club/Xbotics-Embodied-AI-Handbook)

本文按**六大部分、逐讲**写清：每讲教什么、有什么特色、学完能做什么——方便按图索骥，也方便判断「这一周该打开哪一讲」。

---

## 总架构：六大部分 + 五个阶段项目

课程不是 21 个平行专题，而是一条能力递进链：

```text
底座（系统怎么转）→ 模块化视觉操作 → 端到端策略 / VLA
→ 强化学习 → Agent 编排 → VLN 导航 → 世界模型 → 综合答辩
```

| 部分 | 讲次 | 解决的核心问题 | 阶段项目 |
|------|------|----------------|----------|
| Part 1 系统基础 | L1–L4 | 机器人是闭环系统，不是一个模型 | 基础控制闭环 |
| Part 2 视觉操作 | L5–L7 | 看见、对准、抓住并恢复失败 | 视觉定位与模块化抓取 |
| Part 3 端到端 | L8–L13 | 从 Pipeline 走到 Policy / VLA | 端到端操作策略学习 |
| Part 4 强化学习 | L14–L16 | 用交互优化：运控、后训练、真机 | 与策略/运控能力衔接 |
| Part 5 VLN | L18–L19 | 语言如何驱动导航与评测 | 语言驱动导航评测 |
| Part 6 前沿综合 | L17、L20–L21 | Agent、世界模型、拼成答辩 | 移动 + 操作综合答辩 |

**建议学习顺序**：L1→…→L16 → **L17 Agent** → **L18–L19 VLN** → **L20 世界模型** → **L21 答辩**（编号上 L17 属 Part 6，但应插在 VLN 之前学）。

硬件锚点包括 SO101、xLeRobot、Imeta-Y1、Unitree G1；工具链覆盖 ROS2、LeRobot、MuJoCo、ManiSkill、Isaac Lab 等。每讲强调**真机优先、仿真兜底**。

## 第一部分：机器人系统基础（第 1–4 讲）

> **部分定位**：先把「身体」和「闭环」立住。很多课一上来就讲 VLA，学生却不知道动作如何被执行。

### 第 1 讲：具身智能导论 —— 从大模型到物理世界智能体

**教什么**  
从「AI 能答对，机器人却可能抓偏」出发，建立具身智能与传统 AI 的根本差异：输出从文本/标签变成会改变环境的动作，系统必须在观察—决策—行动—反馈中持续闭环。讲清物理世界的实时性、安全性、可行性、反馈等约束，并梳理传统 Pipeline、模仿学习、强化学习、VLA、世界模型五条技术路线及常见混合关系。配套最小二维 reaching 闭环 Demo，让状态、动作、反馈与数据记录「转起来」。

**特色**
- 用「说得对 vs 做得成」把后续感知、几何、控制、安全串成一张地图，而不是名词清单
- 双路径同一套概念：有硬件 / 无硬件都能跟
- `code/lecture01` 最小 Python 二维 reaching，不依赖机械臂即可跑通闭环

**学完能做什么**  
画出闭环图，说明各技术路线分工，并运行、复盘一个最小控制 Demo。

---

### 第 2 讲：机器人系统架构 —— 硬件、软件与 ROS2

**教什么**  
回答「模型会预测动作，不等于机器人能可靠执行」。以六关节臂移到目标为贯穿案例，讲清本体、传感器、执行器、计算、通信、电源与安全等硬件要素，以及驱动、中间件、控制、感知、策略、应用与数据等软件分层。建立状态上行、指令下行的双向数据流；介绍 ROS2 的 Node、Topic、Service、Action、Launch，并说明 VLA / 模仿学习 / RL 在系统中的位置与边界。

**特色**
- 物理部署图 + 功能分层图双视角，避免只背概念
- 统一 Topic 命名（如 `/joint_states`、`/action_command`）贯穿全章，养成接口契约习惯
- 强调单位、维度、限位、频率、安全与 episode 记录——后面所有策略课都回扣这里

**学完能做什么**  
画出软硬件架构图，并用 ROS2 概念检查一个最小闭环是否完整。

---

### 第 3 讲：机器人本体与控制基础

**教什么**  
把「policy 输出的 action 到底是什么」落到机器人身体上：自由度、关节空间 / 末端空间、开环与闭环、位置 / 速度 / 力矩控制，以及正逆运动学与 PID 的基础作用。进一步讨论动作空间设计、动作尺度、控制频率、安全约束，以及同一任务在桌面臂、移动操作、人形上的差异——不理解本体，就无法正确解读 ACT、Diffusion、VLA、RL 里的 action。

**特色**
- SO-101 真机「动作空间对比」：关节绝对/相对、末端位姿等不同口径对照
- 无硬件可用 MuJoCo 等仿真对比同一动作在不同表示下的表现
- 从硬件结构 → 控制 → action 设计 → 部署失败的工程复盘链

**学完能做什么**  
解释模型 action 与具体本体、控制接口的对应关系，并设计合理的动作空间。

---

### 第 4 讲：传感器、坐标系与相机模型

**教什么**  
围绕「从传感器到可执行目标」：外感知、本体感知、接触感知，以及采样、标定、时间同步、ROS2 消息、TF 与坐标变换。核心实操是 RGB-D 反投影与 camera→base 变换，完成「点击图像像素 → 输出 base_link 下目标点」。本讲聚焦测量与时空对齐；目标检测与 6D 位姿留给第 6、7 讲。

**特色**
- 贯穿 Demo：图像点击选点 + 深度反投影 + 外参到基座
- 系统讲多传感器对齐、感知误差如何变成执行偏差
- 覆盖 SO-101、xLeRobot、IMU/力觉等坐标系需求

**学完能做什么**  
完成 RGB-D 点击取点与坐标转换，并排查标定 / 同步 / TF 导致的偏差。

**阶段项目（Part 1）**：给定目标点，完成状态读取 → 动作生成 → 接近目标（真机或仿真）。

---

## 第二部分：机器人视觉操作（第 5–7 讲）

> **部分定位**：在端到端之前，先走通可解释的模块化流水线——出了问题才知道查感知还是控制。

### 第 5 讲：仿真环境与操作任务搭建 —— MuJoCo 与 Isaac Lab 入门

**教什么**  
不是单纯安装手册，而是教「如何把真实任务正确翻译成仿真任务」。用任务目标、机器人模型、场景物体、观测、动作、物理参数、成功判定等框架拆解任务。两条主线并行：机械臂 reach / pick-place（MuJoCo 看模型与物理；Isaac Lab 看观测 / 动作 / 奖励 / 并行评测），以及 Unitree G1 locomotion（站立、行走、扰动恢复）。对照 Sim2Real 差异，强调记录、复盘与可解释失败。

**特色**
- 双平台分工清晰：MuJoCo 轻量理解物理；Isaac Lab 面向 RL 与并行
- 机械臂 + G1 运动多条 Demo 线，统一用同一套「任务拆解」框架解读
- 目标是「能解释 Demo 为何失败」，而不只是跑通

**学完能做什么**  
把真实操作 / 运动任务拆成可仿真、可评测、可复盘的标准仿真任务。

---

### 第 6 讲：机器人感知与位姿估计

**教什么**  
回答「检测框不等于能抓取」。建立识别—定位—定姿三层目标，对比模块化 Pipeline 与端到端感知；给出从图像到执行的标准抓取流水线。覆盖检测 / 分割 / 点云、6D 物体位姿与抓取位姿生成，以及手眼标定（AX=XB）、坐标变换与误差传导。实验含真机流程与 Open3D / ManiSkill 等无硬件路径。

**特色**
- 全链路闭环：检测 → 分割 → 点云 → 位姿 → 抓取候选 → 手眼 → 执行
- 多平台感知需求对照（桌面臂、移动操作、人形）
- `code/lecture06` 手眼标定与相关脚本，把「几何」落到可改代码

**学完能做什么**  
搭建「RGB-D → object / grasp pose」的模块化感知流水线，并理解各环节失效如何传导。

---

### 第 7 讲：机器人操作技能 —— 抓取、放置与失败恢复

**教什么**  
第 6 讲给出物体位姿，本讲把它变成可执行技能：从 object pose 生成预抓取、抓取、抬升、放置、退出等动作，用状态机保证「上一步未完成，下一步不执行」，并通过夹爪 / 视觉 / 日志做成功判定与失败恢复。两个任务——方块 A→B（自上而下）与竖直瓶子侧向抓取入盒——共用程序骨架，体现姿态与容器约束差异。

**特色**
- 完整 pick-place 状态机；`code/lecture07` 支持 Mock / SO-101 / ManiSkill 多后端
- 失败码分类（抓偏、抓空、滑落、碰盒沿等）+ 结构化日志复盘
- 模块化操作的「成功标准」写进程序，而不是口头约定

**学完能做什么**  
把位姿转成带检查与恢复的操作状态机，并分析任务成败原因。

**阶段项目（Part 2）**：视觉目标定位 + 模块化抓取。

---

## 第三部分：端到端机器人操作（第 8–13 讲）

> **部分定位**：策略主战场——从「为何要端到端」到「数据 → 模仿学习 → VLA 微调 → 前沿」。

### 第 8 讲：端到端策略导论 —— 从 Pipeline 到 Policy

**教什么**  
对比手写感知—规划—控制 Pipeline 与端到端 policy：当接触、形变、长尾场景难以写规则时，用网络从观测映射动作。定义 policy 为 π(o)→a（或 π(a|o)），讲清观测 / 动作的多种口径（关节 vs 末端、绝对 vs 相对、单步 vs action chunk），并给出 state policy → 视觉运动策略 → 语言条件策略 → VLA 的谱系。强调评估必须 rollout，部署前用检查单核对接口与安全。

**特色**
- 用经典端到端案例建立直觉，再落到本课程符号体系
- 仿真中跑通第一个策略闭环，避免「只听定义」
- 明确边界：端到端替代写不出规则的环节，不替代运动学与安全底层

**学完能做什么**  
定义 policy、选对观测 / 动作接口，完成一次策略闭环 rollout 与部署检查。

---

### 第 9 讲：操作数据闭环 —— 采一份能训练的数据集

**教什么**  
立论「瓶颈常在数据，不在算力」：用多样性、质量、跨本体迁移等证据说明数据如何决定上限。讲遥操作采集方式，以 SO-101 + LeRobot 为标准格式，覆盖 episode 结构、相机命名、动作 / 状态字段与质检，并完成一段抓取数据采集实验。

**特色**
- 真机主从臂采集 + 无硬件仿真 / 键盘等同格式路径，保证「格式先统一」
- 与 Hugging Face / LeRobot 生态对齐，数据可直接进后续训练讲
- 为后面 RL 自动造数、失败回流埋下伏笔

**学完能做什么**  
按 LeRobot 规范采集、检查并交付一份可用于训练的操作数据集。

---

### 第 10 讲：模仿学习实战 —— ACT、Diffusion 与 Flow Matching

**教什么**  
从行为克隆的两堵墙——误差累积与多模态动作被 MSE「抹平」——引出「学分布而非单点」。分别深入 ACT（action chunking + CVAE）、Diffusion Policy、Flow Matching，并在 LeRobot / LIBERO 上完成训练、部署与曲线 / 失败分析。讲清 chunk 执行、temporal ensembling 等工程细节。

**特色**
- 三条生成式主线一张地图，避免只学一个缩写
- 紧扣 LeRobot 默认实现细节，论文与仓库对齐
- 实验强调成功率 + rollout 视频，不只看 loss

**学完能做什么**  
训练并部署 ACT 等生成式模仿学习策略，并解释 BC 失败与生成式策略的对应关系。

---

### 第 11 讲：VLA 模型导览 —— 从 OpenVLA 到 π0 家族

**教什么**  
沿「理解世界（LLM→VLM→VLA）」与「操控世界（RL→IL→生成式策略）」两条线汇合，讲 Vision / Language / Action 三块拼图与动作解码路线（离散 token vs 连续扩散 / 流匹配）。导读 OpenVLA、π₀、π₀-FAST、π₀.₅、VLA-0、SmolVLA 等代表：架构、数据、动作头、开源权重与适用场景，建立选型直觉。

**特色**
- 代表模型对比表，服务「选哪个上自己的臂」而不是背论文名
- 覆盖实验室臂、移动操作、人形等多本体联合训练语境
- 直接为第 12 讲微调、第 15 讲 VLA 后训练铺路

**学完能做什么**  
读懂主流 VLA 架构图，判断某模型适合哪种任务与硬件。

---

### 第 12 讲：VLA 微调实战 —— 从全量 SFT 到 LoRA 上真机

**教什么**  
在「动多少参数 × 用什么训练信号」框架下，讲全量 SFT、LoRA / QLoRA 等 PEFT，以及数据准备、多卡训练与显存账本。重点把通用 checkpoint 适配到自有机器人与任务，并讲透迁回真机时的口径、延迟、相机与动作尺度等 Sim2Real / Real2Sim 问题。

**特色**
- LoRA 等显存友好路径，降低「只有实验室大卡才能微调」的门槛
- OpenPI / LeRobot 工程链路与 checkpoint 部署检查清单
- 微调与接口核对并重，避免「训得动、接不上」

**学完能做什么**  
在自有数据上用 LoRA 微调 VLA，并完成仿真 / 真机部署与口径核对。

---

### 第 13 讲：VLA 前沿 —— 跑得更快、记得更久、用上全身

**教什么**  
前沿地图课（偏综述、少实验），沿三道工程难题展开：**实时推理**（控制频率与推理延迟的矛盾及调度 / 系统 / 投机等思路）、**长时记忆**（从隐式上下文到显式记忆与分段）、**人形全身 VLA**（loco-manipulation 与全身协调）。帮助建立「下一波落地往哪走」的判断，而不是堆论文列表。

**特色**
- 三条正交研究线，便于和 Part 4 运控、Part 6 Agent / 世界模型对照
- 用具体延迟与控制周期讲清「快」为何是工程问题
- 为综合答辩选题提供前沿坐标

**学完能做什么**  
说出 VLA 在实时、记忆、全身控制上的主要方向与工程价值。

**阶段项目（Part 3）**：端到端操作策略学习——数据、checkpoint、曲线、执行视频与失败分析。

---

## 第四部分：强化学习（第 14–16 讲）

> **部分定位**：训练信号从「示教标签」换成「环境奖励」；从仿真 PPO 到后训练，再到真机 off-policy。

### 第 14 讲：强化学习入门 —— 从策略梯度到 PPO

**教什么**  
在宇树 G1 等仿真任务上建立 RL 词汇（状态、动作、奖励、episode、GAE 等）。沿 **REINFORCE → A2C → PPO** 三级阶梯，在同一环境 / 网络 / 预算下对照：每级解决上一级的方差、基线、稳定性问题。可加码动作跟随等更难任务，展示任务变难时算法差距如何放大。

**特色**
- 大规模并行仿真的 on-policy 训练直觉
- 三算法 diff 对照（同一套评测口径），知识点写在「差异」里
- 与人形运控场景绑定，避免纯 CartPole 玩具感

**学完能做什么**  
把机器人任务写成 MDP，并用 PPO 在仿真中训练行走 / 跟随类策略。

---

### 第 15 讲：GRPO 后训练 —— 让 VLM 学会数数、让 VLA 自我提升

**教什么**  
从 PPO 的 critic 在 LLM 后训练里成本过高出发，讲 GRPO：同 prompt 采一组输出、组内均值作基线、保留 clip 与参考模型约束。实验一：用规则奖励让小型 VLM 学会可验证任务（如「数数」）。实验二：把同一外壳套到「动作即离散 token」的 VLA，做仿真上的自我提升，并讨论相关工程框架。

**特色**
- 把 DeepSeek 系后训练脉络接到具身 VLA，而不是停在纯 NLP
- 可验证奖励 + 格式奖励，强调「RL 外环与策略本体解耦」
- 单卡可感的小实验 + 接到 SO-101 仿真任务的大实验，梯度清晰

**学完能做什么**  
用 GRPO + 可验证奖励做 VLM / VLA 后训练，并设计规则判分函数。

---

### 第 16 讲：Off-policy 强化学习 —— 从仿真提速到真机落地

**教什么**  
真机样本极贵，on-policy「采完即弃」不划算。引入 off-policy：行为策略与目标策略解耦、replay buffer、Q 学习传播稀疏成功。在 SO-101 类任务上爬算法阶梯（从表格方法到连续控制、再到像素级），再讲大规模并行 off-policy 与人形场景。压轴人类在环、视觉奖励分类器等真机走法（如 HIL-SERL 思路与 LeRobot 移植），完成接触型真机 RL 认知。

**特色**
- 与第 9 / 12 讲共用 SO-101 语境，形成「数据—策略—RL 提升」闭环
- 稳定性配件（双 Q、目标网络等）逐级讲清「为什么能训稳」
- 概念一件、命令一件的真机落地视角

**学完能做什么**  
选用 off-policy 路径高效利用经验，并理解人类在环真机 RL 的流程要点。

---

## 第五部分：视觉语言导航 VLN（第 18–19 讲）

> **部分定位**：操作解决「手」，导航解决「脚」与空间指令。建议在第 17 讲 Agent 之后学习。

### 第 18 讲：VLN 理论基础

**教什么**  
定义 VLN：依据自然语言指令在未知环境中完成空间移动的多模态序贯决策，形式化为部分可观测 MDP；讲清观测（RGB-D、位姿、指令、历史）与动作空间。系统对比 VLN 与 SLAM、VLA、通用操作机器人的边界；梳理细粒度 / 粗粒度 / 目标物体导航、对话式、长时程等任务范式；介绍 Habitat 等仿真器，以及 SR、SPL 等指标与主流数据集演进。

**特色**
- 用对比表厘清「导航 ≠ 桌面 VLA ≠ 纯 SLAM」
- 任务范式分层 + 多环境扩展（室内到更开放场景）的地图式写法
- 仿真器与多指标联合评测的方法论，服务第 19 讲实操

**学完能做什么**  
形式化描述 VLN 问题，选对仿真器 / 数据集 / 指标，并设计合理实验对比。

---

### 第 19 讲：VLN 实操与评测

**教什么**  
沿「架构—学习—知识」回顾 VLN 方法演进：从 Seq2Seq / 注意力与数据增强，到 Transformer / 双尺度图记忆与跨模态预训练，再到 LLM / VLM 驱动与「预训练→SFT→RFT」范式。动手在仿真中运行代表基线与较新模型，记录轨迹与 SR / SPL 等指标，理解从「反应式动作预测」到「推理引擎驱动导航」的能力跃迁。

**特色**
- 三阶段方法图谱：每阶段核心瓶颈与突破一一对应
- 仿真实操对比指标，理论课不空转
- 与 `code/lecture18`、`code/lecture19` 配套，便于复现

**学完能做什么**  
在 Habitat 等环境中运行并评测 VLN 模型，并解释各代方法优劣。

**阶段项目（Part 5）**：语言驱动导航评测。

---

## 第六部分：Agent、世界模型与前沿进展（第 17、20–21 讲）

> **建议顺序**：先 L17，再学完 Part 5，再 L20 → L21。

### 第 17 讲：Robot Agent —— 任务规划与技能调用

**教什么**  
（正文亦称 Embodied Agent）从 Chatbot 到 LLM Agent（规划、记忆、工具、行动 + Harness），再接到机器人：四层架构 Agent / Harness / Skill / Robot Runtime——LLM 不直接控电机。讲 ReAct、结构化工具调用、Skill 与 Tool 的区别、慢系统与快系统协作，以及任务合约、技能合约、验收与证据等工程化概念。Demo 用 LangGraph 调用 mock skills，完成「找物→导航→抓取→放置→验收」类长程分解。

**特色**
- 冰箱取水等故事板把抽象 Agent 讲成可感流程
- 从数字 Agent 演进到 Embodied Agent 的阶段清晰，避免「套个 prompt 就叫 Agent」
- `code/lecture17` 可跑的 skill 调用仿真，对接后续 VLN / 操作技能

**学完能做什么**  
设计带 Harness 的 Embodied Agent，把 LLM 规划与机器人 Skill 安全对接。

---

### 第 20 讲：世界模型 —— 预测、规划与数据飞轮

**教什么**  
承接 VLA「现在该做什么」，世界模型追问「做了之后世界会怎样」。区分 VLA、动作条件世界模型、世界动作模型（WAM）与传统仿真器；讲 latent 想象、视频先验、与策略共训等路线，以及读懂 WAM 所需的核心概念。指向语言驱动的移动 + 操作综合任务，代码在 `code/lecture20`。

**特色**
- 「行动前先预演」的直觉 + 与 VLA / 仿真器对照表，降低概念混淆
- 与第 13 讲记忆 / 想象、第 16 讲数据效率相互呼应
- 为答辩里的「失败如何回流成数据」提供理论位置

**学完能做什么**  
区分世界模型与 VLA / 仿真器，并说明其在规划与数据飞轮中的角色。

---

### 第 21 讲：具身智能前沿进展 —— 综合闭环与课程答辩

**教什么**  
梳理近年工程主线：通用机器人基础模型与多本体、长程任务（Agent + VLN + VLA + 检查 / 恢复）、人形全身与灵巧操作、开放世界与数据规模、数据飞轮与失败优先级、评测与产品化指标。综合 Demo 示例：「找到红色方块，放到蓝色区域」——Agent 规划 → 导航 → 感知 → 策略 / 规则抓放 → 验收 → episode 记录 → 失败回流。交付答辩材料：架构图、成功率、失败 case、下轮采集计划。

**特色**
- 全课程总框架收束：感知→决策→控制→数据→训练→部署→评测→失败→再采集
- 有硬件（如 xLeRobot / G1）与无硬件（LangGraph + 仿真栈）双 Demo 设想
- 既是前沿扫盲，也是个人深扎路线（操作 / VLN / 运控 / 世界模型 / 数据工程）的岔路口

**学完能做什么**  
拼出端到端具身系统 Demo，完成答辩交付，并选定后续专精方向。

**阶段项目（Part 6）**：移动 + 操作综合答辩。

---

## 这套「逐讲设计」好在哪里

把 21 讲摊开看，优点不只是「覆盖面广」，而是**每一讲在链路上有不可替代的位置**：

1. **前后咬合**：L4 坐标 → L6 位姿 → L7 状态机 → L8 policy 接口；L9 数据 → L10 ACT → L11–12 VLA；L14 PPO → L15 GRPO → L16 off-policy；L17 Agent → L18–19 VLN → L20 世界模型 → L21 拼装。  
2. **先可解释，再端到端**：Part 2 模块化操作让你有「拆锅查修」的能力，再学 Part 3 才知道端到端省掉了什么、又埋了什么坑。  
3. **双路径贯穿**：几乎每讲都有真机锚点与仿真兜底，自学与开课都能推进。  
4. **失败是一等内容**：状态机失败码、rollout 视频、规则奖励、HIL、答辩失败 case——训练的是排错习惯，不只是刷成功率。  
5. **多本体不偏科**：桌面臂、移动操作、人形运控、语言导航同框，综合答辩强制「移动 + 操作」。
