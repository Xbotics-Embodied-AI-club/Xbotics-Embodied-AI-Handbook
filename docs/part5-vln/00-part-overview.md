# 第五部分：视觉语言导航 VLN（第 17–18 讲）

## 部分定位

第五部分系统介绍 **视觉语言导航（Vision-and-Language Navigation, VLN）**：研究如何使移动机器人理解自然语言指令，结合视觉感知与空间推理能力，在未知环境中自主完成目标定位与路径规划，实现从「听懂指令、理解环境、规划行动」到「到达目标位置、完成导航任务」的具身导航能力。

本部分围绕 VLN 的**任务定义、典型范式、评价基准、方法演进与实践部署**展开，帮助学习者理解 VLN 从早期指令跟随模型，到 Transformer 视觉语言预训练，再到大语言模型驱动具身智能体的发展过程，并为后续操作任务（Part 2 移动操作、Part 6 Agent）提供基础导航技能 **`navigate_to` 能力**。

## 阶段项目：语言驱动导航评测

基于典型 VLN 模型与仿真环境，完成语言指令驱动的导航任务实验，理解视觉观测、语言理解与动作决策之间的关系，并通过轨迹结果与评价指标分析模型导航能力。
