# 一、总定位

《Xbotics 具身智能教程（21 讲）：从机器人基础到具身前沿》是一门面向具身智能、机器人、人工智能、自动化、计算机视觉、智能制造等方向学习者的系统实践教程。

具身智能是一个高度交叉的方向，涉及机器人本体、传感器、控制、仿真、数据采集、模仿学习、强化学习、VLA、世界模型以及真实系统部署等多个方面。对于初学者来说，最大的困难不是某一个知识点特别难，而是不知道应该从哪里开始、各个模块之间是什么关系、哪些内容必须学、哪些内容可以先了解。

目前市面上还缺少一套从入门到深入、面向具身智能完整系统的统一教程。很多学习资料要么偏向传统机器人，从运动学、动力学、控制理论一路讲起，内容庞杂、周期很长，初学者很容易陷入细节；要么只讲大模型、VLA 和前沿论文，忽略机器人硬件、控制、数据和系统工程，导致学生虽然知道模型名称，却不理解模型如何真正接入机器人、如何采集数据、如何部署到真机、如何分析失败。

本课程的目标，就是在这两者之间建立一条更适合 AI 时代学习具身智能的路径。我们不会把机器人所有基础知识从头完整讲一遍，也不会只停留在模型概念和论文解读，而是从真实具身智能系统出发，抽取机器人基础、系统架构、感知、控制、仿真、数据、模型训练和部署中的关键内容，按照「先建立全局地图，再逐步拆解模块，最后形成完整闭环」的方式展开。

课程将结合 SO101 教学机械臂、xLeRobot 移动操作套件、Imeta-Y1 科研机械臂和 Unitree G1 人形机器人等硬件体系，同时配合 ROS2、LeRobot、ManiSkill、Isaac Lab 等开源工具，让学生既能理解前沿方向，也能真正动手跑通实验。

我们希望通过 3 个月的系统学习，让学生不只是「听说过具身智能」，而是能够：

- 理解一个具身智能系统如何组成
- 知道 VLA、VLN、模仿学习、强化学习、世界模型、Agent 分别处在系统的什么位置
- 完成基础仿真与真机 Demo
- 采集和理解机器人数据
- 具备继续深入学习和参与真实项目的能力

**一句话**：本课程的目的不是让学生碎片化追热点，而是建立清晰、系统、可实践的具身智能学习框架，完成从「看热闹」到「入门上手」的跨越。

**课程规模**：全教程 **21 讲**、**六大部分**（见下表）。较早期「十八讲」规划，已增加 VLN 两讲，并将世界模型与前沿进展分设独立讲次。

## 教程主线

```
具身智能导论 → 机器人系统架构 → 机器人本体与硬件基础 → 传感器与感知基础
→ 仿真导论 → 机器人感知与位姿估计 → 视觉操作策略 → 端到端学习导论
→ 数据采集 → 模仿学习训练 → 生成式动作策略 → VLA 理论 → VLA 实操
→ 强化学习基础 → 强化学习运控 → 强化学习后训练
→ Embodied Agent（Part 6）→ VLN 理论 → VLN 实操（Part 5）
→ 世界模型（Part 6）→ 前沿进展与综合答辩（Part 6）
```

## 组织方式（SLAM 十四讲式）

1. **系统地图清晰**：围绕完整机器人系统展开，而非零散概念
2. **理论和代码绑定**：每一讲都有可运行 Demo
3. **从小模块到大系统**：控制、坐标、感知、抓取 → 数据、学习、VLA、Agent
4. **重视工程实践**：调参、失败分析、交付物
5. **可以自学复现**：无硬件可用仿真完成核心实验
6. **强调系统能力**：形成数据、训练、部署、评测和失败回流闭环

## 每讲双路径结构

- 实验步骤 / 作业交付 / 常见失败与复盘 / 参考开源项目
