# 第 1 讲：具身智能导论 —— 让 AI 进入物理世界

> **所属部分**：第一部分 · 机器人系统基础  
> **代码**：[`code/lecture01/`](../../code/lecture01/)

## 1.1 教学目标

本讲帮助学生建立具身智能的整体认知。学生需要理解，具身智能不是简单把大模型接到机器人上，而是让智能体依托身体，在真实或仿真的物理环境中完成感知、理解、决策、执行、反馈和学习。

本讲结束后，学生应能够回答：

- 什么是具身智能？
- 具身智能和传统机器人有什么区别？
- 为什么具身智能不能只讲模型？

## 1.2 核心知识点

1. 具身智能的基本概念：身体、环境、任务、感知、动作与反馈
2. 传统 AI 与具身智能的区别：从「生成答案」到「完成任务」
3. 具身智能系统闭环：任务输入 → 感知 → 状态估计 → 目标生成 → 规划/策略 → 控制执行 → 反馈检测 → 数据回流
4. 机器人任务的基本组成：本体、传感器、执行器、控制器、数据、模型与安全约束
5. 传统机器人 Pipeline、模仿学习、强化学习、VLA 的区别
6. 世界模型与 World Action Model 的基本思想
7. 人形机器人与全身智能的发展趋势
8. 典型应用场景：桌面抓取、移动操作、工业分拣、商超零售、家庭服务、实验室自动化、人形机器人
9. Xbotics 教学硬件体系：SO101、xLeRobot、Imeta-Y1、Unitree G1

## 1.3 教学设计

本讲不急着讲复杂算法，而是先建立完整具身智能系统地图。围绕任务「机器人把桌上的物体放到指定位置」：

```
语言/任务输入 → 多模态感知 → 状态估计 → 任务理解 → 子目标生成
→ 策略模型或规划器 → 控制器 → 执行器 → 反馈检测 → 失败恢复 → 数据记录与模型迭代
```

## 1.4 课堂案例

**案例名称**：从「AI 会回答」到「机器人会执行」

对比三个系统：

1. ChatGPT 回答「如何抓杯子」
2. VLM 识别图片中的杯子
3. 机器人真正抓起杯子并放到目标位置

## 1.5 体验式 Demo

**Demo 名称**：观察一个最小具身闭环

| 版本 | 内容 |
|------|------|
| 有硬件 | SO101 末端移动到 `target_eef = [0.20, 0.05, 0.12]`，记录 joint/eef 命令与轨迹 |
| 无硬件 | MuJoCo / Isaac Lab 机械臂或 G1 仿真，末端接近目标点 |

## 1.6 实验步骤

1. 启动硬件或仿真环境
2. 读取机器人初始状态
3. 输入目标点
4. 运行最小控制器或策略脚本
5. 观察是否接近目标
6. 修改目标点位置
7. 记录轨迹和误差变化
8. 分析过冲、震荡、延迟或坐标系错误

## 1.7 作业交付

1. 具身智能系统模块图
2. 传统 Pipeline、模仿学习、VLA 对比图
3. 最小控制或仿真运行代码
4. 机器人运动轨迹图
5. 30 秒以内 Demo 视频或录屏
6. 说明：为什么具身智能不能只讲大模型？

## 1.8 常见误区与复盘

**常见误区**：具身智能 = 大模型控机器人；端到端一定优于 Pipeline；仿真成功 = 真机成功；数据越多一定越好。

**复盘问题**：为什么需要状态反馈？为什么 VLA 不能替代所有模块？为什么失败样本很重要？
