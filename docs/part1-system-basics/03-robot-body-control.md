# 第 3 讲：机器人本体与控制基础

## 本讲学习目标

学完本讲后，学生应能够：
1. 理解机器人本体的基本组成，包括机械结构、驱动系统、传感系统、控制系统和计算系统；
2. 解释自由度、关节、连杆、末端执行器、关节空间和末端空间等基础概念；
3. 区分开环 / 闭环控制，以及位置控制、速度控制、力矩控制的基本含义和适用场景；
4. 理解正运动学、逆运动学和 PID 控制在机器人运动控制中的基础作用；
5. 理解模型输出的 action 如何与具体机器人本体、动作空间、动作尺度、控制频率和安全约束相关联。

## 3.1 本讲主线：从机器人身体到 action 含义

### 3.1.1 为什么这一讲很重要？

- 具身智能不是单个模型，而是感知、决策、控制、执行和数据闭环组成的系统；
- 模型输出的 action 不是抽象数字，而是具体机器人上的真实物理指令；
- 不同机器人本体对应不同动作空间、控制接口和安全约束；
- 不理解机器人本体，就很难理解 VLA、ACT、Diffusion Policy、强化学习中的 action 到底代表什么。

### 3.1.2 机器人本体如何影响智能系统？

- 决定机器人能做什么任务；
- 决定动作空间如何设计；
- 决定数据如何采集；
- 决定模型如何训练；
- 决定部署时是否稳定；
- 决定为什么会出现抖动、超限、延迟和失败。

### 3.1.3 本讲整体逻辑

```text
机器人硬件结构
↓
自由度、关节与末端执行器
↓
控制方式与运动学
↓
动作空间设计
↓
动作尺度与控制频率
↓
真机 / 仿真部署
↓
失败复盘与工程调参
```

## 3.3 运动结构基础：自由度、关节、连杆与末端执行器

### 3.3.1 自由度

- 自由度表示机器人可以独立运动的方向或关节数量；
- 移动底盘通常关注平面运动自由度；
- 机械臂通常关注关节自由度和末端空间自由度；
- 人形机器人包含腿、腰、手臂、头部和手指等大量自由度。

### 3.3.2 关节

- 旋转关节；
- 移动关节；
- 主动关节；
- 被动关节；
- 关节角度；
- 关节速度；
- 关节限位；
- 关节力矩。

### 3.3.3 连杆

- 连杆连接不同关节；
- 多个连杆和关节组成机械臂运动链；
- 连杆长度和结构决定工作空间；
- 连杆质量影响动力学和控制稳定性。

### 3.3.4 末端执行器

- 二指夹爪；
- 吸盘；
- 灵巧手；
- 工具端；
- 相机；
- 焊枪；
- 打磨头；
- 其他任务工具。

### 3.3.5 关节空间与末端空间

- 关节空间描述每个关节的位置、速度或力矩；
- 末端空间描述夹爪或工具在三维空间中的位置和姿态；
- 模型可以输出关节动作，也可以输出末端动作；
- 控制器或 IK 求解器负责在关节空间和末端空间之间转换。

## 3.5 控制基础：开环、闭环与常见控制方式

### 3.5.1 开环控制

- 系统下发动作后不根据执行结果及时修正；
- 控制逻辑简单；
- 容易受误差、摩擦、外力和结构间隙影响；
- 适合简单、确定性强的场景。

### 3.5.2 闭环控制

- 系统持续读取当前状态；
- 根据目标状态和当前状态之间的误差更新控制指令；
- 真实机器人通常依赖闭环控制保持稳定；
- 具身智能系统中的执行过程需要持续观察、反馈和修正。

### 3.5.3 最小闭环结构

```text
目标状态
↓
控制器
↓
机器人执行
↓
当前状态反馈
↓
误差计算
↓
更新控制指令
```

### 3.5.4 位置控制

- 输入目标关节角或目标末端位姿；
- 适合教学机械臂、桌面抓取和大多数入门任务；
- 动作直观，部署相对安全。

### 3.5.5 速度控制

- 输入关节速度、末端速度或底盘速度；
- 适合连续移动、视觉伺服和移动底盘控制；
- 常见接口包括 cmd_vel。

### 3.5.6 力矩控制

- 输入目标关节力矩；
- 适合四足机器人、人形机器人、柔顺控制和高动态任务；
- 对控制器、动力学建模和安全保护要求更高。

## 3.6 PID 与低层控制：从误差到稳定执行

### 3.6.1 PID 的基本思想

- P：比例项，当前误差越大，控制动作越大；
- I：积分项，用于处理长期累积误差；
- D：微分项，用于抑制过冲和震荡。

### 3.6.2 PID 与机器人动作表现

- P 太小，动作慢；
- P 太大，容易过冲；
- D 不合适，容易震荡；
- 控制频率太低，动作不平滑；
- 目标变化太快，控制器可能跟不上。

### 3.6.3 模型 action 与低层控制器

- 模型输出的 action 通常不能直接粗暴下发给电机；
- 需要经过限幅、滤波、插值、平滑和安全检查；
- 低层控制器负责把高层动作转成稳定的机器人运动；
- VLA 或大模型更适合作为高层策略，而不是直接高频电机控制器。

## 3.7 运动学基础：从关节空间到末端空间

### 3.7.1 正运动学

- 从关节状态计算末端位姿；
- 输入是各关节角度；
- 输出是末端执行器的位置和姿态。

joint state → end-effector pose

### 3.7.2 逆运动学

- 从目标末端位姿反推关节命令；
- 输入是目标位置和姿态；
- 输出是关节角度或关节运动命令。

target pose → joint command

### 3.7.3 逆运动学的常见问题

- 同一个末端位姿可能对应多组关节解；
- 目标点可能不可达；
- 接近奇异位形时动作可能异常；
- 需要考虑关节限位、速度限位和碰撞约束。

### 3.7.4 为什么很多策略输出 eef delta？

- 相比直接输出全部关节角，末端增量更接近任务空间；
- 对抓取、推动、移动到目标附近等任务更直观；
- 可以由控制器或 IK 求解器转换为关节命令；
- 适合连续闭环控制。

## 3.9 动作尺度、归一化与控制频率

### 3.9.1 动作尺度

- 关节角可能以弧度表示；
- 末端位置可能以米表示；
- 夹爪开合可能是 0 到 1；
- 底盘速度可能是 m/s；
- 不同维度数值范围不同，会影响模型训练和部署。

### 3.9.2 Action normalization

- 将不同动作维度转换到相近数值范围；
- 常见范围包括 [-1, 1]；
- 模型输出后需要反归一化为真实控制指令；
- 反归一化尺度必须和机器人硬件、控制接口、训练数据一致。

### 3.9.3 动作尺度带来的部署问题

- 尺度太大：抖动、过冲、撞击、超限；
- 尺度太小：动作缓慢，任务无法完成；
- 训练数据和部署机器人尺度不一致：模型输出失真；
- 仿真和真机动作尺度不一致：仿真成功但真机失败。

### 3.9.4 控制频率

- 控制频率表示控制器每秒下发多少次指令；
- 例如 10Hz、50Hz、100Hz；
- 控制频率太低，动作容易不连续；
- 控制频率太高，对通信、控制器和安全性要求更高。

### 3.9.5 模型推理频率

- 模型推理频率表示模型每秒生成多少次 action；
- 模型推理频率和控制频率不一定相同；
- 大模型通常难以直接高频控制电机；
- 常见方式是低频模型输出，高频控制器执行。

### 3.9.6 推理频率与控制频率的衔接

- action hold；
- interpolation；
- filter；
- action smoothing；
- low-level controller；
- safety check。

## 3.10 人形机器人为什么更复杂？

### 3.10.1 从机械臂到人形机器人的复杂度变化

- 单机械臂通常固定在底座上；
- 人形机器人需要同时控制腿、腰、躯干、双臂、头部和手部；
- 人形机器人既要完成操作任务，又要保持全身稳定。

### 3.10.2 站立和平衡

- 手臂动作会改变重心；
- 重心超出支撑范围可能导致摔倒；
- 底层控制器需要持续维持平衡。

### 3.10.3 行走和转向

- 涉及步态、接触、摩擦和动态稳定；
- 腿部控制比固定机械臂更复杂；
- 地面变化会影响执行效果。

### 3.10.4 腰部、上身与手臂协调

- 抓远处物体时可能需要转腰、移动上身或调整脚步；
- 上身动作和腿部平衡强耦合；
- 任务空间和全身控制空间需要协同。

### 3.10.5 双臂协同

- 搬运、开门、整理物品等任务需要双臂配合；
- 需要考虑双臂同步、力分配和碰撞避免；
- 双臂动作不能只看单个末端。

### 3.10.6 安全约束

- 人形机器人更高、更重、更接近人类活动空间；
- 失控风险比小型机械臂更高；
- 高层模型通常需要配合全身控制器和安全模块。

9. 记录关节位置曲线和末端轨迹；
