# 六、教程实施原则

## 1. 每讲教学结构

| 比例 | 内容 |
|------|------|
| 30% | 核心概念 |
| 40% | Demo 实操 |
| 30% | 调参、复盘与失败分析 |

**每讲交付**：代码、数据、可视化、实验视频、评测表、失败分析

## 2. 五个阶段项目（21 讲）

教程采用「每讲有 Demo + 分阶段项目」模式（全课程 **21 讲**，共 **五个** 阶段项目）：

| 阶段 | 讲次 | 项目 |
|------|------|------|
| 一 | L01–L04 | 机器人基础控制闭环 |
| 二 | L05–L07 | 视觉目标定位与模块化抓取 |
| 三 | L08–L13 | 端到端操作策略学习 |
| 四 | L18–L19 | 语言驱动导航评测（VLN） |
| 五 | L17、L20–L21 | 移动 + 操作综合答辩 |

- 每讲都有 Demo；最后拼成完整系统

## 3. 安全原则

1. 教师确认后上电
2. 速度限制、空间边界、急停
3. 学生不得直接改低层危险参数
4. G1 真机只运行验证过的安全动作
5. RL 优先仿真训练验证
6. 真机实验保留日志和视频
7. 端到端模型部署前：仿真 + 低速测试

## 4. 第一讲课堂组织建议

第一讲建议采用四段式组织：

```text
概念导入 → 系统地图 → 路线对比 → Demo 体验
```

1. **概念导入**：从学生熟悉的大模型能力切入，追问“为什么会回答抓杯子的方法，还不等于机器人能稳定抓住杯子”。
2. **系统地图**：让学生亲手画出任务、感知、状态、策略、控制、反馈和数据回流之间的关系。
3. **路线对比**：用同一个任务比较传统 pipeline、模仿学习、强化学习和 VLA，强调真实工程通常采用混合架构。
4. **Demo 体验**：先运行二维 reaching 闭环，再讨论它与真实机械臂之间还差本体、传感器、运动学、驱动和安全等哪些模块。

趋势内容只承担“为后续课程埋下伏笔”的作用，不在第一讲展开算法细节。可简要提到机器人数据集、低成本开源硬件、VLA、世界模型、人形机器人和数据飞轮。
