## 1. 流水线总览

```
                        ┌──────────────┐
  深度图 (depth.png) ──▶│  步骤 1       │──▶ masked_depth
  掩膜   (mask.png)  ──▶│  掩膜筛选     │    (非目标置零)
                        └──────┬───────┘
                               ▼
                        ┌──────────────┐
                        │  步骤 2       │──▶ 3D 点云 (X, Y, Z)
                        │  反投影生成   │    create_from_depth_image()
                        └──────┬───────┘
                               ▼
                        ┌──────────────┐
                        │  步骤 3       │──▶  Z 轴裁剪后点云
                        │  直通滤波     │    numpy 切片
                        └──────┬───────┘
                               ▼
                        ┌──────────────┐
                        │  步骤 4       │──▶ 干净点云
                        │  精洗去噪     │    统计 → 体素
                        └──────┬───────┘
                               ▼
                        ┌──────────────┐
                        │  步骤 5       │──▶ target_clean.pcd
                        │  导出 .pcd    │    用于位姿估计
                        └──────────────┘
```

### 核心公式：针孔相机反投影

$$
Z = \frac{\text{depth}(u, v)}{\text{depth\_scale}}, \qquad
X = \frac{(u - c_x) \cdot Z}{f_x}, \qquad
Y = \frac{(v - c_y) \cdot Z}{f_y}
$$

解压后，需要完成三步准备工作：复制同一帧的 RGB、深度图和 mask，写入相机内参文件，再检查四个输入文件是否齐全。

**第 1 步：复制同一帧的 RGB、深度图和 mask。** 不同对象包的帧名前缀略有差异，下面用 `find` 自动选择第一组同时包含 RGB、depth 和 mask 的帧：

```bash
src_dir=$(find data/raw_rgbd -type d -name "coffee_mug_1*" | head -n 1)

rgb_file=$(
  find "$src_dir" -type f -name "*.png" \
    ! -name "*_depth.png" ! -name "*_mask.png" ! -name "*_depthmask.png" | sort |
  while read -r f; do
    base="${f%.png}"
    if [ -f "${base}_depth.png" ] && { [ -f "${base}_depthmask.png" ] || [ -f "${base}_mask.png" ]; }; then
      printf '%s\n' "$f"
      break
    fi
  done
)

if [ -z "$rgb_file" ]; then
  echo "未找到同时包含 RGB、depth 和 mask 的帧" >&2
  exit 1
fi

base="${rgb_file%.png}"
depth_file="${base}_depth.png"
mask_file="${base}_depthmask.png"
if [ ! -f "$mask_file" ]; then
  mask_file="${base}_mask.png"
fi

cp "$rgb_file" data/rgbd_object_demo/rgb.png
cp "$depth_file" data/rgbd_object_demo/depth.png
cp "$mask_file" data/rgbd_object_demo/mask.png
```

**第 2 步：写入相机内参文件。** `pipeline_from_syllabus.py` 运行时会同时检查 `depth.png`、`mask.png` 和 `intrinsics.json`；如果没有这一步，会报出“缺少必要文件: data/rgbd_object_demo/intrinsics.json”。RGB-D Object Dataset 使用 Kinect 风格的 640×480 深度图；如果只做课堂点云流程演示，可以使用下列常用近似内参。若你有该帧的精确标定参数，应优先替换为真实值。

### 3.1 加载输入数据

本小节对应脚本启动后的“加载数据”阶段，说明 `pipeline_from_syllabus.py` 会读取哪些文件，以及如何把深度图、mask 和相机内参加载到内存中。

```python
import numpy as np

mask = np.asarray(Image.open("data/rgbd_object_demo/mask.png").convert("L")) > 0
print(f"掩膜: {mask.shape}, 前景 {mask.sum():,}/{mask.size:,} ({mask.sum()/mask.size*100:.1f}%)")

# 内参
with open("data/rgbd_object_demo/intrinsics.json") as f:
    K = json.load(f)
print(f"内参: fx={K['fx']}, fy={K['fy']}, cx={K['cx']}, cy={K['cy']}, "
      f"depth_scale={K['depth_scale']}")
```

**输出示例**：

## 4. 步骤 1 — 掩膜筛选

### 4.1 原理

将深度图与 Mask 逐元素相乘，非目标像素深度值置为 0。后续反投影时只有目标区域生成 3D 点。

### 4.2 代码

```python
# 核心操作：一行乘法
masked_depth = depth_mm * mask

print(f"掩膜后有效深度像素: {np.count_nonzero(masked_depth):,}")
```

## 5. 步骤 2 — 反投影生成

### 5.1 原理

使用 Open3D 内置函数 [`create_from_depth_image()`](https://www.open3d.org/docs/release/python_api/open3d.geometry.PointCloud.html#open3d.geometry.PointCloud.create_from_depth_image)，将掩膜筛选后的深度图映射为 3D 点云。该函数内部执行针孔相机反投影公式。

### 5.2 代码

```python
# 毫米 → 米
depth_m = masked_depth.astype(np.float32) / 1000.0

# 构造 Open3D 图像 + 内参对象
o3d_depth = o3d.geometry.Image(depth_m)
h, w = masked_depth.shape
intr = o3d.camera.PinholeCameraIntrinsic(w, h, K["fx"], K["fy"], K["cx"], K["cy"])

# 反投影
pcd = o3d.geometry.PointCloud.create_from_depth_image(
    depth=o3d_depth,
    intrinsic=intr,
    extrinsic=np.eye(4),   # 不旋转
    depth_scale=1.0,        # 已转米
    depth_trunc=100.0,      # 不截断
    stride=1,
)
print(f"生成 {len(pcd.points):,} 个 3D 点")
```

## 6. 步骤 3 — 空间粗裁（直通滤波）

### 6.1 原理

用 numpy 布尔切片沿 Z 轴裁剪点云，移除：
- **Z < 0.2 m**：桌面以下的无效点
- **Z > 1.5 m**：距离过远的背景点

### 6.2 代码

```python
points = np.asarray(pcd.points)
z = points[:, 2]

# numpy 切片
z_mask = (z >= 0.20) & (z <= 1.50)

# 构造新点云
pcd_crop = o3d.geometry.PointCloud()
pcd_crop.points = o3d.utility.Vector3dVector(points[z_mask])
if pcd.has_colors():
    pcd_crop.colors = o3d.utility.Vector3dVector(np.asarray(pcd.colors)[z_mask])

print(f"滤波前: {len(points):,}")
print(f"滤波后: {len(pcd_crop.points):,}")
print(f"Z 范围: [{z.min():.3f}, {z.max():.3f}] m")
```

## 7. 步骤 4 — 精洗去噪

### 7.1 子步骤 (a)：统计滤波去噪

**原理**：对每个点计算到 k 个最近邻的平均距离，剔除平均距离过大的孤立飞点。

**代码**：

```python
pcd_stat, outlier_idx = pcd.remove_statistical_outlier(
    nb_neighbors=20,   # 邻居数
    std_ratio=2.0,     # 标准差倍数阈值
)
print(f"剔除飞点: {len(pcd.points) - len(pcd_stat):,}")
```

### 10.1 参数速查

| 参数 | 默认值 | 范围 | 说明 | 调大 | 调小 |

## 11. 常见问题

### Q1：反投影后点云有空洞

**原因**：深度传感器在物体边缘、反光表面产生无效深度值。

**解决**：对掩膜做膨胀（dilate）覆盖边缘，或对深度图做中值滤波。

### Q2：统计滤波剔除了目标本身

**原因**：`std_ratio` 过小或 `nb_neighbors` 过大。

**解决**：增大 `std_ratio`（2.0→3.0），减小 `nb_neighbors`（20→10）。

### Q3：体素降采样后目标几何变形

**原因**：`voxel_size` 过大，网格太粗。

**解决**：抓取任务建议 `voxel_size` ≤ 0.01 m，精细物体 ≤ 0.005 m。

### Q4：想用自己的数据

1. 准备 `depth.png`（16-bit，毫米）、`mask.png`（二值）、`intrinsics.json`
2. 放入一个目录，运行：
   ```bash
   python pipeline_from_syllabus.py --demo-dir 你的目录 --no-vis
   ```

### Q5：使用 RealSense 相机实时采集

```bash
# 安装依赖
pip install pyrealsense2

# 运行 USB 模式
python interactive_depth_pipeline.py --source usb --output-dir output
```
